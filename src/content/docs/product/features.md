# Product Features

## AI-Powered Document Validation

The core engine cross-checks 10-20 supporting documents per dossier against programme-specific rules. It identifies missing documents, incorrect formats, expired attestations, and mathematical inconsistencies in real time.

**Key capabilities:**
- Multi-document cross-referencing
- Programme-specific rule enforcement (CEE, BEG, ECO4, etc.)
- Real-time error flagging with severity levels
- Confidence scoring for each validation check

---

## Pre-Configured Programme Rules

iverif.io ships with embedded logic for major EU energy subsidy programmes:

| Programme | Status |
|-----------|--------|
| CEE (Certificats d'Economies d'Energie) | Fully supported |
| BEG (Bauenergiegesetz) | Fully supported |
| ECO4 (Energy Company Obligation) | Fully supported |
| Other EU programmes | On request |

Rules cover document requirements, validity periods, format specifications, and cross-document consistency checks.

## Complete Audit Trail

Every validation action is timestamped and logged:
- Document upload timestamps
- Validation check results with confidence scores
- User actions and corrections
- System decisions and rule triggers

**Export formats:** PDF report, CSV data dump, API JSON
