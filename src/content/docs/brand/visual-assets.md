## Asset Usage Guide

### Website Implementation

```html
<!-- Open Graph -->
<meta property="og:image" content="https://iverif.fr/assets/website/og-image.png" />

<!-- Twitter -->
<meta name="twitter:image" content="https://iverif.fr/assets/website/twitter-header.png" />

<!-- Favicon -->
<link rel="icon" type="image/png" href="/assets/website/favicon.png" />
```
